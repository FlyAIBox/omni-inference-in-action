# 文档目录 | Documentation

本目录包含项目的所有文档资料。

## 📁 目录结构

### getting-started/
快速入门指南，帮助新用户快速上手项目。

**内容包括：**
- 环境配置
- 安装步骤
- 第一个推理示例
- 常见问题解答

### deployment/
部署文档，涵盖不同环境下的部署方案。

**子目录：**
- `docker/` - Docker 容器化部署
- `kubernetes/` - K8s 集群部署
- `bare-metal/` - 裸机部署指南

### benchmarks/
性能基准测试文档，包含各种场景下的性能测试结果和分析。

**内容包括：**
- 测试方法论
- 性能指标说明
- 对比分析报告
- 优化建议

### tutorials/
详细教程，深入讲解各个推理框架的使用。

**子目录：**
- `vllm/` - vLLM 框架教程
- `sglang/` - SGLang 框架教程
- `optimization/` - 性能优化技巧

### api/
API 接口文档，说明各个模块的接口定义和使用方法。

**内容包括：**
- RESTful API 文档
- Python API 文档
- 接口调用示例
